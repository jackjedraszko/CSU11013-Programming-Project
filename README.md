# Project Title
US Flight Data App

## Description
This app is an interactive dashboard for exploring data from US domestic flights.

## Features
- Home
The landing page with navigation buttons to access the maps, charts and tables pages.
- Maps
Visualises flight routes and origins on an interactive US map including top 10 most popular airports, hover over states to see flight data for that region.
- Charts
Displays graphs and charts summarising flight data from cancellations to top flight destinations with filters to see more specific data.
- Tables
An interactive flight board using Java Swing's JTable, click any column header to sort ascending or descending, scrollable table to look through flights, filters available to see specific flight data.
